## 🟦 بارز أفراد — barezz.com

منصة عربية متخصصة في **مراجعة وتحسين السير الذاتية بالذكاء الاصطناعي**، مبنية للسوق السعودي والخليجي بالعربية أولاً.

- مراجعة ذكية تكشف نقاط الضعف وتقترح تحسينات ملموسة
- تحسين تلقائي يرفع توافق السيرة مع الوظيفة المستهدفة وأنظمة الـATS
- أدوات مساندة ودليل مهني شامل
- نظام اشتراكات ودفع إلكتروني كامل

**دوري:** بنيت المشروع من الصفر — تصميماً وتطويراً وتشغيلاً
**الحالة:** 🟢 منتج حي يخدم عملاء يومياً → [barezz.com](https://barezz.com)
**التقنيات:** Next.js · TypeScript · Supabase · Claude API

## 🟩 بارز أعمال — barez.sa

نظام **إدارة موارد بشرية (HRIS) سعودي متكامل** متعدد الشركات، يغطي دورة حياة الموظف من التوظيف إلى نهاية الخدمة.

- رواتب متعددة العملات ومسيرات متعددة، داخل السعودية وخارجها
- حضور وانصراف بتحقق متعدد العوامل يمنع التلاعب
- توظيف متكامل من الإعلان إلى التعيين
- إجازات وعُهد وسلف وخطابات بدورات اعتماد موثقة
- عزل كامل للبيانات بين الشركات

**دوري:** بنيت النظام من الصفر — تصميماً وتطويراً وتشغيلاً
**الحالة:** 🟢 نظام حي قيد التشغيل → [barez.sa](https://barez.sa)
**التقنيات:** Python · Flask · SQLite
**الكود:** 🔒 خاص · [صفحة الفكرة](https://github.com/ab1ob/barez-erp-overview)

## 📊 لوحة الموارد البشرية — Power BI

داشبورد موارد بشرية عربي كامل من **7 صفحات** مبني بصيغة PBIP/TMDL/PBIR المفتوحة.

- الملخص التنفيذي: السعودة، الدوران، متوسطات الرواتب والأداء
- قمع توظيف كامل لـ21,000 طلب (تقديم ← مقابلة ← عرض ← تعيين)
- رواتب وتدريب وحضور وإجازات وعُهد — كل صفحة بمؤشراتها
- نموذج دلالي: 12 جدولاً، 15 علاقة، 23 مقياس DAX بالعربي
- ثيم احترافي موحّد ولوحة فلاتر مكررة بكل الصفحات

**دوري:** بناء كامل — نمذجة البيانات، المقاييس، التصميم البصري
**التقنيات:** Power BI · DAX · Power Query (M) · TMDL
**الكود:** 🔒 خاص — عرض حي متاح عند الطلب

## 📈 نظام مؤشرات الأداء

منظومة KPI كاملة مبنية بمنهجية صارمة: **«المؤشر يُبنى من القيمة والأثر، لا من الرقم المجرد»**.

- لوحة قيادة موحّدة بنظرة شاملة على أداء المنشأة
- دليل مؤشرات موثّق: التعريف، الحساب، مستويات التقييم لكل مؤشر
- تغطية خمسة أقسام: التسويق والمبيعات، استقطاب المواهب، التعلم والتطوير، نجاح العملاء، تطوير البرمجيات
